## 141B 킹왕짱 (seq1280) — 핵심 성과
- **seq 프로브** (`scripts/probe_141b_maxseq.py`): base 1회 로드 후 in-process로 seq 512→1280 스윕, GTT 피크 실측.
  결과 **seq1280까지 GTT≤54 통과**(피크 49.35GiB). grad-ckpt 덕에 **메모리가 seq를 거의 안 먹음**(512→1280 GTT +3GiB) → **병목은 메모리가 아니라 시간**.
- 드라이버 `run_141b_highseq_master.sh <SEQ> <EPOCHS>`: 검증→스왑가드→smoke(8)→풀학습, 25스텝 주기저장 + watchdog(SwapFree<4G/OOM/wedge 하드중단).
- 실측 471s/step, 2에폭 78스텝 10.5h. GPU 웨지 0, OOM 0, GTT 49/56 안정.
- **판정**: seq 2.5배 자체는 val 개선 없음(ReAct 샘플이 짧아 긴 컨텍스트가 패딩). 원본(0.62, 3ep) 못 넘음 = 에폭 수 교란(2 vs 3, val이 계속 하강 중이라 3ep면 더 낮았을 것). ⚠️`--lora-mlp` 금지(Mixtral MLP=전문가), attention-only 유지.

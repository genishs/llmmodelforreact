## 1. Vulkan vs ROCm — 학습이 아니라 "추론"의 선택지
- **ROCm** = AMD 전용 컴퓨트 스택(현재 gfx1151 학습에 사용). **Vulkan** = 벤더 중립 API, 아무 GPU에서 돎.
- **ML에서**: 추론은 Vulkan 성숙(`llama.cpp`·MLC), **학습은 미성숙**(Burn+wgpu·ggml finetune은 니치, PyTorch Vulkan은 폐기). 
- **결론**: 우리 학습 스택(PyTorch+ROCm+HQQ, 123B LoRA)은 **Vulkan으로 대체 불가**. 그러나 **추론/서빙에는 Vulkan(llama.cpp)이 오히려 적합**.

## 2. 학습 → 배포 다리
`PyTorch LoRA 학습 → peft merge_and_unload → GGUF 변환 → GGUF 양자화(Q4_K_M 등) → llama.cpp(Vulkan) 서빙`. 검증된 표준 워크플로.
- ⚠️ **GGUF 양자화 ≠ HQQ** → 변환 후 품질 재평가 1회 권장.
- 서빙 필요 메모리는 **어댑터(1GB)가 아니라 머지된 base 모델 크기**가 결정.

## 3. 배포 토폴로지 — 모델 크기와 한 세트
| 토폴로지 | 설명 | 적합 모델 |
|---|---|---|
| **A. 중앙 서버형** | 8060/서버가 모델 물고 API, 사용자는 씬 클라이언트 | **123B/72B (이 방식뿐)** |
| **B. 온디바이스형** | 사용자 기기에서 통째 구동 | **7B/14B GGUF Q4** (Vulkan 이식성) |
| **C. 하이브리드** | 큰 모델 서버 + 작은 모델 로컬, 티어링 | 혼합 |

- **필요 메모리(GGUF Q4 대략)**: 7B~5GB / 14B~9GB / 32B~20GB / 72B~40GB / **123B~70GB(Q2~35GB)**.
- **123B는 4060(VRAM 8~16GB)에서 실용 불가** (CPU 오프로드로 "돌긴" 하나 대화형 불가). → 123B는 8060/서버 중앙 서빙.
- "GPU 필수"가 아니라 **"모델 크기만큼 메모리 + 빠르려면 GPU"** (llama.cpp는 CPU/하이브리드도 가능).
- **8060의 두 역할**: (1) 학습 공장 (2) 큰 모델 서버.

## 4. 추론 서비스 아키텍처 (챗봇 수준)
```
[웹 UI(React)] ─HTTP─ [앱/백엔드 서버] ─HTTP─ [추론 엔진=llama.cpp server(Vulkan)]
  자연어 질문/스트리밍     프롬프트 조립·맥락주입·세션·인증      모델 상주(warm)+토큰생성+OpenAI호환 API
```
- **"추론 프로세스"와 "답 반환 서버"는 한 컴포넌트**(llama.cpp server)임.
- **앱 서버 층**이 어시스턴트다움 담당: 챗 템플릿(⚠️ 학습 때 포맷=추론 때 포맷), 코드 맥락 주입, 세션, 스트리밍.
- 실무 필수 3: **모델 warm 상주** / **챗 템플릿 일치** / **SSE 스트리밍**.
- MVP는 앱 서버 생략하고 UI↔엔진 직결로 시작 가능.

## 5. Claude Code 수준(에이전트형) — 진짜 벽은 "모델"
챗봇 3-티어로는 부족. 에이전트형에 추가로 필요: **툴 사용(function calling) + 에이전트 루프 + IDE 확장 + 맥락/권한**.
- **MCP(Model Context Protocol)** = 툴·데이터를 표준으로 붙이는 배관(위치 = 툴 층). **방향은 맞으나 필수는 아님**(하드코딩도 가능); 가치는 표준화·재사용·생태계.
- 🔴 **핵심 병목 = MCP 배관이 아니라 모델의 에이전트 능력**. 우리 어댑터는 **React 코드 변환(좁은 태스크)** 튜닝이라 에이전트 오케스트레이션 신뢰도는 별개 문제. Claude Code가 잘 도는 건 프런티어 모델이 그 목적에 훈련됐기 때문.
- 🎯 **실용 지름길**: 하네스를 직접 만들지 말고 **기존 오픈소스 에이전트(Cline·Continue — MCP 지원, OpenAI 호환 / Aider)** 에 **우리 llama.cpp 엔드포인트를 물리기**. 에이전트 층 재사용, 우리는 **모델 품질 + 서빙**에 집중.
